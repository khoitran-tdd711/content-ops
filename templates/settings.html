OneUp connection

OneUp (oneupapp.io) is the service that actually posts to Instagram/LinkedIn/Facebook/TikTok on your behalf — this app hands scheduled posts off to it via API. Get your API key from oneupapp.io/api-access (you'll need a OneUp account with your social accounts already connected there). Leave the API key blank if you'd rather use the manual "send to OneUp" fallback for now.

Google Drive (for .zip files and folders)

This lets the app open a Drive .zip (or a folder with loose photos in it) and send every photo straight to OneUp, instead of you having to paste individual photo links. It also powers the Board's "Find Drive links" button, which searches Drive by task title and suggests a match for you to accept. Needs a Google service account key (a JSON file from Google Cloud) — create one, then paste its full contents below. After saving, click "Test connection" to see the service account's email address, then share your Drive folders with that exact email (same as sharing a folder with a coworker). Leave this blank if you'd rather keep pasting individual photo links — that still works.

Scopes "Find Drive links" searches to inside this one folder, so matches are more accurate. Leave blank to search all of Drive shared with the service account.

AI caption generation (Claude)

Powers the "Generate caption" button on the Calendar's publish popup — it sends that task's actual carousel photos to Claude, which drafts a caption following Akka's rules (hook first, grounded in real facts, translated call-to-action with the right @handle, up to 5 SEO hashtags). Get an API key from console.anthropic.com. This is separate from the OneUp key above. Leave blank to hide the button.

Account handle per language

The exact @handle Claude puts in the call-to-action, per language — e.g. @akka_france for a French post. A task with no language set uses the English handle. Add a language's handle here as soon as you start posting in it; if it's missing, "Generate caption" will show a clear error instead of guessing the wrong handle.
